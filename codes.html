Comment rédimer les codes PocketChampion

Suivez ces cinq étapes pour récupérer vos récompenses dans le RPG mobile.

1Téléchargez le jeu mobile.
2Ouvrez votre profil de dresseur.
3Accédez aux réglages.
4Collez le code de rédemption.
5Réclamez les récompenses dans la boîte mail.

La plupart des codes cadeaux ne peuvent être utilisés qu'une fois par personnage. Si un code échoue, vérifiez l'orthographe, la disponibilité du serveur et la période de l'événement.
